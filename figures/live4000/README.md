# Иллюстрации для статьи: 4000 реально работающих NSSF

Два сопоставимых научных графика на русском языке, строго по **табл. 5** редакции
«Адаптивный иерархический контроль целостности профилей сетевых функций 5G:
метод и экспериментальная проверка на 4000 действующих функциях».

Источник: 27 детерминированных испытаний одного массива из 4000 реально
работающих NSSF. Эти рисунки **не** представляют новые эксперименты,
сетевые задержки или измерения CPU. Примерно 93,38 % экономии касается
только углублённых проверок; примерно 88,50 % — только количества
сериализованных байт для координатора.

## Форматы
* `fig_01_deep_checks.png` и `fig_01_deep_checks.svg` — число углублённых проверок.
* `fig_02_coordinator_data.png` и `fig_02_coordinator_data.svg` — объём данных координатору.

Файлы в артефакте GitHub Actions `article-figures-live4000`.
PNG экспортируется с разрешением 320 DPI; SVG содержит векторные линии и текст.

## Локальный запуск
```bash
python -m pip install matplotlib==3.10.6
python figures/live4000/make_figures.py --output-dir figures/live4000/out
```

Метрики в `table5_live4000.csv`; скрипт проверяет числа по оригинальной таблице,
чтобы незаметная подмена значений приводила к ошибке.
